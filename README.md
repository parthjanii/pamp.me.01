# Pamper Me MVP

Amazon-first public gifting profile MVP in a Turborepo.

## Apps
- `apps/web`: Next.js public wishlist + APIs
- `apps/mobile`: Expo mobile shell
- `packages/types`, `packages/api-client`, `packages/ui-tokens`

## Commands
- `npm install`
- `npm run dev`
- `npm run test`
- `npm run db:migrate`
- `npm run db:seed`
- `npm run build`
